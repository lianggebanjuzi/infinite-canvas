# 文本拆分节点 + 图片节点多图模式

新增节点类型 `text-split`（文本拆分）：上游接文本节点或手动粘贴文档，按拆分符一键拆成多个可增删的拆分框；下游图片节点接入后按拆分框数量逐条生成图片，全部图片收纳在同一图片节点内、上下切换查看。

## 一、数据模型与类型（`src/v1/types/flow.d.ts`）

- `NodeType` 增加 `'text-split'`。
- 新增 `TextSplitParams { sourceText: string; delimiter: string; segments: string[] }`（存在 `node.params`）。
- `FlowNode` 增加可选字段 `outputImages?: Array<{ url: string; origin?: ImageOrigin; prompt?: string }>`（文本拆分模式下生成的多图）与 `imageIndex?: number`（当前查看的图序号）。字段全部可选，旧工程反序列化无需迁移。

## 二、文本拆分节点定义（新文件 `src/v1/nodes/text-split.ts`，仿 `text-gen.ts`）

- 注册 `type:'text-split'`，`defaultParams: { sourceText:'', delimiter:'\n', segments:[] }`。
- `canRun` 返回 `'文本拆分节点无需运行'`（拆分在面板点击完成，不走引擎）；`run-engine.run()` 中 text-gen 分派旁加保护分支兜底。
- `src/v1/main.ts` import 注册。

## 三、连线规则（`src/v1/state/flow-state.ts`）

- `canConnect`（L351）：`to` 为 text-split 时仅允许 from 为 `text-gen`（文本→文本限制对 text-split 放开这一条）；`from` 为 text-split 时仅允许 to 为 `image-gen`。
- `getUpstreamTextPrompts`（L183）：上游为 `text-split` 时返回其 `segments`（trim 后非空项），供图片节点消费。
- 拆分框内容变化 / 重新拆分后调用 `dirty.markUpstreamChanged` 标下游 stale。

## 四、指令面板 UI（`src/index.html` + `src/v1/ui/cmd-panel.ts`）

- 选中 text-split 节点时面板切换到「拆分编辑模式」（复用现有 `textgen` class 切换模式）：
  - 原文 textarea：有上游 text-gen 节点时自动填入其 `outputText`（连线变化即同步），也可手动粘贴/编辑。
  - 拆分符输入框（默认换行，支持 `\n` 转义识别）。
  - 「拆分」按钮：`sourceText.split(delimiter)` → trim → 去空 → 写入 `segments`（拆分符天然不带入）；「一键清空」按钮清空全部拆分框（及原文）。
  - 拆分框列表：每段一个 textarea + 删除按钮，底部「+ 添加拆分框」。所有编辑实时写回 `params.segments` 并标下游 stale。
- 隐藏与 text-split 无关的提示词框/chips。

## 五、卡片 UI（`src/v1/canvas/card-view.ts`）

- text-split 卡片：仿 `pcard-text` 样式，显示「N 段」+ 各段首行预览；有 in/out 端口；无运行/查看大图按钮。
- image-gen 卡片多图模式：`outputImages.length > 1` 时主视觉为查看器——上下箭头按钮切换 + `i/N` 指示；点击查看大图用当前张。单张/旧节点行为不变。

## 六、图片节点消费拆分结果

- `nodes/image-gen.ts` `canRun`：直接上游存在有 segments 的 text-split 节点时，允许空 prompt 运行（segments 即提示词）。
- `ui/cmd-panel.ts` `sync()`：直接上游为 text-split（有 segments）时——隐藏「张数」chip，显示提示条「张数由文本拆分节点决定（N 段）」；提示词输入框隐藏。
- `engine/run-engine.ts`：`runBatch` 前置分支——检测上游 text-split segments 后走新的 `runSplitBatch`：每段一次 `Backend.generateImage(segment, {...count:1})` + `pollTask`（沿用现有并发/超时/取消模式），每张完成后**增量** append 到 `node.outputImages` 并 notify（生成一张显示一张），不再 `createResultCard` 拆卡片；参考图仍走 `getReferenceImages`，比例/分辨率/模型仍由图片节点 chips 决定。

## 七、新建节点入口（`src/v1/canvas/interactions.ts`）

- `_showNewNodeMenu`（L444-451）候选分支：from=text-gen → 增加「文本拆分」；from=text-split → 仅「图片」。画布右键菜单自动来自注册表，无需改。

## 涉及文件

`types/flow.d.ts`、`nodes/text-split.ts`（新）、`main.ts`、`state/flow-state.ts`、`ui/cmd-panel.ts`、`canvas/card-view.ts`、`engine/run-engine.ts`、`canvas/interactions.ts`、`index.html`、`styles/app.css`（拆分框/多图查看器样式）。

## 验证

`npm run build`（tsc 类型检查）+ 启动后手动链路验证：文本节点输出 → 连文本拆分 → 拆分（拆分符不带入、增删框、清空）→ 连图片节点（张数 chip 消失）→ 生成 → 单节点内上下切换多图。
