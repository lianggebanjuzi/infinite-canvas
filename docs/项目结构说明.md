# Infinite Canvas 2.1 项目结构

> 最后更新：2026-08-19

## 顶层文件

| 文件 | 用途 |
|------|------|
| `main.py` | 应用入口，启动 pywebview 窗口 |
| `launcher.py` | 启动器（负责初始化环境后调用 main） |
| `requirements.txt` | Python 依赖 |
| `package.json` | Node.js 依赖（Vite/TypeScript） |
| `tsconfig.json` | TypeScript 编译配置 |
| `vite.config.ts` | Vite 打包配置 |
| `providers_data.json` | 供应商/密钥/模型配置（运行时数据） |
| `settings.json` | 其他设置（图片保存路径等） |

---

## 后端（Python）

### `backend/api/` — API 核心层

| 文件 | 职责 |
|------|------|
| `unified_api.py` | **统一 API 路由层**：根据模型类型自动选择 OpenAI Images / Gemini Native / FluxPort 视频协议；处理异步任务轮询、图片保存、错误分类 |
| `provider_api.py` | **供应商管理**：读写 `providers_data.json`，拉取模型列表（`fetch_models`），测试连接 |
| `settings_api.py` | 设置管理（图片保存路径等） |
| `image_api.py` | 图片处理工具（缩略图生成、路径工具） |
| `video_api.py` | 视频生成任务管理 |
| `gemini_compat.py` | Gemini 原生协议适配（URL 归一、宽高比映射、响应解析） |
| `model_rules.py` | 模型类型/格式识别规则（从模型名推断是 chat/drawing/video） |
| `errors.py` | 错误类型定义（APIKeyError、RateLimitError、UpstreamError 等） |
| `project_api.py` | 项目管理（.icproj 文件读写） |
| `clipboard_api.py` | 剪贴板操作 |
| `utils.py` | 通用工具函数 |

---

## 前端（TypeScript）

### `src/v1/` — 主业务逻辑

| 文件 | 职责 |
|------|------|
| `main.ts` | V1 入口，初始化 UI 组件 |
| `api.ts` | **前端 API 层**：调用 pywebview 后端接口 |
| `persistence.ts` | 项目保存/加载逻辑 |
| `history-persist.ts` | 历史图库持久化 |
| `save-coordinator.ts` | 保存协调器（原子保存、防重复） |
| `close-guard.ts` | 关闭保护（未保存提示） |
| `reproduce.ts` | 复现功能（根据 json 重建节点） |
| `asset-store.ts` | 资产库管理（成图、对比面板） |

### `src/v1/ui/` — UI 组件

| 文件 | 职责 |
|------|------|
| `settings-panel.ts` | **设置面板**：供应商管理、密钥管理、模型管理（刚才改的就是这个） |
| `toast.ts` | Toast 提示组件 |
| `select.ts` | 自定义下拉组件 |
| `confirm.ts` | 确认弹窗 |

### `src/v1/nodes/` — 节点系统

| 文件 | 职责 |
|------|------|
| `image-gen.ts` | 图片生成节点（文生图/参考图编辑） |
| `text-gen.ts` | 文本生成节点（对话） |
| `video-gen.ts` | 视频生成节点 |
| `base.ts` | 节点基类（状态机、连线、脏标记） |

### `src/` — 其他

| 文件 | 职责 |
|------|------|
| `bridge.ts` | pywebview 桥接层 |
| `main.ts` | 应用初始化 |
| `utils/api.ts` | 通用 API 工具 |
| `utils/uid.ts` | UUID 生成 |

## 关键数据流

```
用户操作 → 前端 (src/v1/)
    ↓ 调用
pywebview 桥接 (bridge.ts)
    ↓
后端 API (backend/api/unified_api.py)
    ↓
FluxPort 中转站 (api.uselg.top / api.ai-media.vip)
    ↓
返回结果 → 前端渲染
```

## 新增/修改时的指引

- **新增 API 格式**：改 `unified_api.py`，加 `ApiFormat` 枚举 + `_build_xxx_payload` 方法
- **新增模型类型**：改 `model_rules.py`，加识别规则
- **UI 组件**：放在 `src/v1/ui/`，样式在 `src/v1/styles/`
- **供应商配置**：改 `provider_api.py`，保持向后兼容（旧格式自动迁移）
