## 7. 遗留风险说明

1. **环境构建怪癖（低风险，已知）**：`npm run build` 在删除旧 `gui/dist` 前会因 safe-delete/trash 报错（WorkBuddy 沙箱对 `fs.rmSync` 的包装）。不影响产物正确性，但影响本地/CI 构建流程体验。建议：构建前脚本先清空 `gui/dist`，或在非沙箱环境构建。
2. **真机 pywebview 未跑（验证边界）**：运行时验证用 Chromium 引擎 + mock 桥替代；`window.pywebview.api` 层与后端真实往返未在运行时覆盖（后端 Python 单测 24/24 通过，前端真实保存/打开/运行依赖的 api 形状在 mock 中做了兼容）。如需最终确认，可在有 WinForms/WebView2 的机器上启动 `main.py` 做一次人工冒烟。
3. **qa-textgen-click.cjs 2 项过期断言未修**：按铁律未改测试脚本；若产品确认新行为（单击不弹、双击弹），需工程师/QA 后续更新该脚本（见 §5 问题 1）。
4. **重命名只影响撤销栈单例**：其余 `history` 系标识符（`historyDrawer`/`historyPersist`/`history.jsonl`/`cmd-text-history` 等）均为不同对象/模块，未受波及（已全库核对）。
