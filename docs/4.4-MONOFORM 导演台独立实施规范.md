# 4.4：MONOFORM 式导演台独立实施规范

> 目标：实现“用 3D 白模、镜头、光照、时间轴预演，再回到 AI 画布创作”的能力。
>
> 重要：这是独立子产品，不要塞进现有 2D 画布，也不要与 4.1–4.3 的稳定性绑定发布。

## 1. 产品边界

### 1.1 必做能力

- 3D 视口、白模人物、基础几何体、粗模场景、本地 GLB/GLTF 导入。
- 场景层级、选中、隐藏、锁定、移动/旋转/缩放、吸附、贴地、聚焦。
- 多镜头、摄像机参数、焦距、画幅、编辑视角/摄像机视角、监看器。
- 参考图叠加、位置/透明度/缩放、是否进入导出。
- 基础灯光：环境、主光、补光、方向、颜色、曝光。
- 人物动作预设、骨骼/IK 调整、保存姿势。
- 时间轴与对象/角色/镜头关键帧；PNG、MP4、工程 JSON 导出。
- 与 Infinite Canvas 的图片、视频、项目资源互相导入导出。

### 1.2 不做

- 角色面捕、面部表情、物理模拟、真实渲染器、多人协作、专业非编。
- 直接复制 MONOFORM 的角色资产、动作文件、模型、纹理、UI、品牌或教程内容。
- 高清放大。

## 2. 架构决定

1. 新建独立目录/入口，例如 `src/director/*`，用标准 TypeScript + Three.js；不迁主应用到 React。
2. 导演台工程使用独立 `.icdirector` JSON，资源以项目相对路径或稳定资源 ID 表达。
3. 从主画布打开导演台时：传入项目 ID、选中图片资源、临时返回通道；导演台保存不改写 2D 画布。
4. 从导演台回传时：导出的 PNG/MP4 通过现有资源导入管线成为素材节点；不把整个 3D 场景塞入 FlowNode。
5. WebGL 不可用时显示静态说明与导入/导出选项，不能导致主程序无法启动。

## 3. 分阶段任务书

### D0：壳与工程文件

- 导演台入口、独立路由/窗口、空工程、新建/打开/保存、撤销/重做、资源路径校验。
- 工程 JSON schema version、迁移、原子写入、最近工程记录。
- 验收：无 Three.js 资源时可创建/保存/重开空工程。

### D1：场景与视口

- Three.js 场景、网格、坐标轴、透视编辑相机。
- 原创占位白模/几何体；场景层级；选择/隐藏/锁定；W/E/R 变换；世界/局部坐标；吸附；贴地。
- GLB/GLTF 导入要限制文件大小、记录原始路径、显示缺资源提示。
- 验收：添加对象、移动、保存、重开后位置/锁定/可见性一致。

### D2：镜头与参考图

- 多摄像机新建、复制、重命名、删除、切换；位置/旋转/焦距/比例。
- 摄像机监看器和编辑视角切换；参考图上传、移动、透明度、缩放、是否导出。
- 验收：同一场景两台相机得到不同构图；导出 PNG 与监看器一致。

### D3：光照与人物

- 环境/主光/补光与曝光；默认灯光恢复。
- 人物需使用本项目合法资产；动作预设、姿态存储、最小可用 IK（四肢末端优先）。
- 验收：光照与角色姿态保存恢复；没有人物骨骼时 UI 降级而不是报错。

### D4：时间轴与导出

- 1–60 秒、FPS、播放头、播放/暂停；镜头、对象 transform、角色状态关键帧。
- 关键帧复制/粘贴/删除、线性/保持插值；PNG 单帧导出。
- MP4 导出必须在独立 worker/编码路径执行，有进度、取消、磁盘空间错误提示；先支持低分辨率/短时长验证。
- 验收：两帧摄像机运动能正确插值并导出；长导出取消后应用可继续使用。

### D5：与主画布互通

- 画布图片可作为导演台参考图导入；导演台 PNG/MP4 一键“加入当前项目资产/插入画布”。
- 保存来源：导出资源 trace 记录 director project id、shot id、camera id、时间点；不暴露内部绝对路径给外部包。
- 验收：从画布选图→导演台构图→导出 PNG→回到画布继续创作，项目重开后来源仍可查看。

## 4. 工程数据建议

```ts
interface DirectorProject {
  format: 'icdirector'; version: number; id: string; name: string;
  scene: DirectorObject[]; cameras: DirectorCamera[]; activeCameraId: string;
  references: DirectorReferenceImage[]; lighting: DirectorLighting;
  timeline: DirectorTimeline; assets: DirectorAssetRef[];
}
```

- object、camera、keyframe 使用稳定 UUID；外部模型与图片使用资源引用，不复制大文件进 JSON。
- 工程导出 ZIP 带 manifest 与实际引用资源；默认不携带 API Key。
- 每一次 schema 变更必须写迁移函数与旧工程 fixture。

## 5. 性能、安全与验收门槛

- 默认限制导入模型顶点/纹理/文件大小；超限先提示简化或拒绝。
- 视口应按设备像素比上限渲染；失焦暂停动画循环；隐藏窗口不持续编码。
- 导入 GLTF/ZIP 视为不可信文件，校验路径和大小；不得执行其中脚本。
- 每个 D 阶段运行 `npm run typecheck`、`npm run build`；D1 起增加最少的 Playwright/手工 smoke（创建对象、保存、重开）。

## 6. 发布策略

导演台以“实验性工具”独立入口发布；D0–D2 稳定前不在主画布操作条放强入口。D4 的 MP4 导出与 D5 画布互通通过后，才将其升级为正式“导演预演”。
