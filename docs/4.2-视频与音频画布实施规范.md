# 4.2：视频与音频画布实施规范

> 目标：把已有的媒体能力做成完整创作功能。视频后端已有基础，不等于功能已完成；音频从能力配置到画布呈现均需补齐。

## 1. 产品边界

### 1.1 视频首期

- 文生视频、图生视频、首帧/尾帧、时长、比例、分辨率、可选音频开关。
- 视频结果本地落盘、画布内预览、下载、加入资产、进入历史、保存项目。
- 允许图片/文本直接连到视频生成节点；不做完整视频剪辑时间线。

### 1.2 音频首期

- 文生音频（音乐/环境/音效由模型 capability 决定）。
- 本地音频文件导入、播放/暂停、波形或时长的轻量展示。
- 音频可作为视频生成节点的直接输入；若供应商不支持，则明确禁用而非假装带音频。
- 不做 DAW、多轨混音、录音、歌词编辑、音频超分。

## 2. 共享媒体模型

扩展 `NodeType` 与端口声明：

```ts
type MediaKind = 'image' | 'video' | 'audio' | 'text';
// 建议新增：video-gen、audio-gen；导入的视频/音频以 isAsset 标记或专门 media-asset 表达。
```

- `image-gen` 输出 image；`text-gen` 输出 text；`video-gen` 输出 video；`audio-gen` 输出 audio。
- video-gen 输入：至少 prompt(text)；可选 image（参考/首帧）、audio（配乐/配音）；只取直接输入。
- audio-gen 输入：prompt(text)；可选 image 仅在模型 capability 明确支持“image conditioned audio”时开放。
- 所有媒体实体要有 `originalPath`、`thumbnail`、`duration`、`mimeType`、`width/height`（适用时）、`trace`；缺失字段必须可降级显示。

## 3. 切片 A：视频前端接通

### A1. 模型与设置

1. `fetchVideoModels()` 从既有 provider/key/model 配置读取 `type='video'` 的可用模型。
2. 增加 `getModelCapabilities()` 的 video schema：`supportsImageReference`、`supportsStartEndFrame`、`supportsAudio`、`seconds`、`resolutions`、`aspectRatios`。
3. 参数面板只显示模型支持的项；切换模型时保留兼容值，移除不兼容值并显示说明。

### A2. 节点与运行

- 从画布创建菜单、图片操作条“生成视频”、右键菜单三处创建同一 `video-gen` 节点。
- 若从图片创建，自动把图作为首帧/参考并建立 reference 边；若从文本创建，写入 prompt 但不伪造图片输入。
- `run-engine` 新增媒体 dispatch，不复制图片生成函数；调用 `VideoAPI.generate_video_async` 和 `get_video_task_result`。
- accepted 后复用 4.0 状态机：本地任务持有 remote task id，轮询错误不换 Key 重投。

### A3. 视频呈现

- 画布卡显示海报帧、时长、比例、状态；点击进入视频查看器。
- 查看器有播放、暂停、静音、循环、下载、复制来源 prompt、继续创作、加入资产。
- 本地路径失效时显示可理解错误与“重新定位/从历史恢复”入口；不让整个卡片崩溃。

**验收 A**：从一张图片创建 5 秒视频→成功播放→保存项目→重开仍可播放；任务失败时可复制 remote id，且源图/节点未被覆盖。

## 4. 切片 B：音频基础设施与节点

### B1. 后端 adapter

新增 `backend/api/audio_api.py`，不得把音频塞进 `video_api.py`。

- 统一 async create/status/download 三段协议；适配器描述 endpoint、payload、状态字段、结果 URL 字段。
- 支持 `audio/mpeg`、`audio/wav`、`audio/ogg` 等下载落盘；生成缩略元数据（时长、大小、MIME），不要解码完整音频进前端。
- 复用 Key/代理/幂等/accepted-task 规则；错误返回脱敏并带远端 task id。

### B2. 音频节点

- 设置页新增 `audio` 能力类型、模型列表和 Key 绑定；旧 provider 数据缺音频字段时迁移为空。
- 创建 audio-gen 节点：prompt、模型、时长/格式（仅 capability 支持时）、生成按钮。
- 导入本地 mp3/wav/ogg 时创建音频素材节点；禁止将整段音频转 base64 放入 `.icproj`。
- 音频卡显示标题、时长、播放控制、波形占位；首期波形可用离线抽样生成，不要求实时频谱。

**验收 B**：未配置音频模型时不出现可运行的音频生成按钮；导入 50MB 音频不让项目 JSON 膨胀；生成后重开项目仍可播放。

## 5. 切片 C：媒体资产、历史与关联

1. 资产抽屉增加图片/视频/音频筛选、搜索、预览、拖入画布、加入/移出资产、下载。
2. 历史记录可展示视频和音频任务：状态、模型、prompt、来源、时长、远端任务 ID（若有）。
3. 视频节点可显式选择一个音频节点作为输入；连线关系显示“音轨/配音参考”，而不是普通 reference。
4. 若当前视频模型不支持音频，连线保留但运行前显示“此模型忽略音频输入”，用户选择切模型或断开；禁止静默丢掉。

## 6. 并发、费用与恢复

- 视频默认每 provider/key 并发 1；音频默认 2；配置常量集中且可显示排队位置。
- 多次点击只会创建本地排队任务，不会直接发多条远端请求。
- 视频/音频超时后显示“已提交，等待恢复查询”，不重投；用户可稍后手动重新查询同一 remote id。
- 项目关闭前检测进行中的媒体任务，提示“继续后台等待 / 取消关闭 / 关闭但保留远端任务记录”。
