# UI/交互审查结果 · 2026-08-18

## 已完成

- 单选节点时自动露出指令面板，减少核心编辑流程的隐藏步骤；仍保留 Tab 呼出、Esc 收起。
- 节点拖动期间使用 requestAnimationFrame 合并卡片与连线刷新，降低高频 mousemove 造成的重排和跟手抖动。
- 卡片补充 grab / grabbing 光标和轻微选中抬升，选中状态更容易理解。
- 补齐键盘焦点环，并尊重 prefers-reduced-motion。
- 指令面板限制最大高度、输入框限制高度并允许滚动；顶部操作条和底部工具条在窄窗口可横向容纳。

## 验证

- TypeScript 类型检查通过。
- Vite 构建通过。构建前需先清理项目内 gui/dist，以绕过当前环境的 safe-delete 拦截。
- 浏览器验证：右键新建图片生成节点后自动选中，面板直接出现，底部按钮变为“运行当前卡”；窄视口下页面无新增错误。
- 浏览器控制台与页面错误检查为空。

## 注意

纯浏览器调试环境没有 pywebview 后端，因此模型列表显示“加载失败”；在桌面宿主内会由后端提供模型列表，这不是本轮 UI 改动导致的问题。
