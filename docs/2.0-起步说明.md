## 四、如何运行

```bash
# 首次（已装过可跳过）
npm install

# 构建前端
npm run build          # = tsc --noEmit && vite build → gui/dist

# 启动程序
python main.py         # 或双击 start.bat
```

日常开发直接用 `检查构建.bat`（类型检查 + 构建一键过）。

## 五、开发约定（重要）

- **开工先 pull**：换电脑时 `git pull` 拉最新，读 `.workbuddy/memory/` 日志了解进度
- **收工动作**：本地 commit（说明写人话）→ **push 必须事先征得用户同意**（勿自动推送）
- **构建坑**：vite 的 `emptyOutDir` 清空 `gui/dist` 会被环境 trash 拦截（safe-delete 报错）——**先手动删 `gui/dist` 再单独跑 build**
- **代码改动流程**：团队协作（架构师方案 → 工程师实现 → QA 回归 → 构建实测），重大变更走专家团队

## 六、2.0 当前功能（2026-08-16 基线）

- 双卡模型：图片卡（image-gen）+ 文本卡（text-gen）
- 文生图出图写回原节点；图生图产出完整图片节点连右边
- 文本节点：卡片就地编辑 + 命令框 AI 处理；图片节点文本模型反推 → 生成文本节点
- 扩图第一版：悬浮框弹层选比例 + 原图拖放 + 白色填充合成 + banana 模型补全
- 失败原因卡片横幅；重跑安全策略（只清纯引擎产出）
- 6 个 smoke 脚本 208 断言全绿

## 七、2.0 路线（来自产品方案 v3）

1. 信任层：原子/自动保存、关闭保护、撤销重做（1-2 周）
2. 档案层：trace 记录、采纳/锁定（建议提前）、复现按钮（2-3 周）
3. 资产层：花材/场景/成图库、标签搜索拖入、提示词模板（3-4 周）
4. 评估层 + 长期：批量变体对比、Agent、模板固化
