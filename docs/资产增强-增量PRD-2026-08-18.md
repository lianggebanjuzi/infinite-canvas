## 2. 产品目标

**一句话**：让「采纳过的图」成为跨项目可复现、可批次对比的资产——配方随采纳落盘、历史按生成批次浏览。

**验收标准（可测量）**：

| # | 验收标准 |
|---|---|
| A1 | 在项目 A 采纳一张图并重启应用后，切换到项目 B：资产库卡片仍显示该图的 prompt / model / 比例 / 分辨率，点击「复现」可重建生成节点与参数（不再空白失败） |
| A2 | 一次生成 4 张：历史抽屉「按批次」视图显示 1 张批次卡（含同批次缩略图组 + 成功计数如 4/4 + 配方摘要）；「按时间」视图仍可逐张浏览 |
| A3 | 批次卡内每张缩略图保留单图能力：查看大图、拖入画布、复现均可用（分组不损失单图复用） |
| A4 | 回归：hashRef 指纹去重主键不变（同一张图跨项目仍只有一条资产记录）；locked 锁定保护语义不变（重跑不顶掉采纳图）；history.jsonl 仍为单行 append-only 模型 |

**三个正交目标**：
1. **跨项目可复现**：配方随采纳落盘（assets.json），资产库成为可复现的策展库（R2）
2. **批次心智对齐**：历史按「一次生成」组织，选图从单图流水升级为批次对比（R3）
3. **数据能力零退化**：不动 jsonl 底层模型、不碰去重/锁定逻辑，本地数据优势保留（约束目标）

## 3. 用户故事（园艺电商设计师视角）

1. As 园艺电商设计师，I want 在项目 A 采纳的绿植主图，切到项目 B 后仍能看到当时的提示词/模型/参数并一键复现，so that 我能跨项目复用成熟配方，不用重新回忆或翻找。
2. As 园艺电商设计师，I want 一次生成 4 张花盆场景图在历史里合并为一张批次卡浏览，so that 我能快速对比同批次结果、选出满意的一张，不用在平铺流水里反复翻找。
3. As 园艺电商设计师，I want 在批次卡内对单张图直接拖入画布 / 查看大图 / 复现，so that 批次分组不损失单张图的复用能力。
4. As 园艺电商设计师，I want 资产卡片显示配方摘要并能复制 prompt，so that 我能把成熟提示词复用到其他产品线的生成。

## 5. UI 变化描述（文字稿，非高保真）

### 5.1 资产库抽屉（asset-drawer）

- 卡片结构由「纯缩略图 + 角标 + hover 动作」扩展为「缩略图 + 配方信息区 + 角标 + hover 动作」：
  - **配方信息区**（卡片下方）：prompt 摘要（1-2 行省略截断）、model、比例/分辨率（小字 chips 或文本行）。
  - **hover 动作**新增「复制配方」按钮（一键复制 prompt 全文；无配方时置灰并提示「配方缺失」）。
  - 「复现」按钮逻辑改为优先读记录配方（R2-3），不再因跨项目反查失败而空白失败。
- **旧记录占位**：无配方字段的资产卡片显示「配方缺失（可经历史反查）」轻提示，复现仍走既有兜底链。

### 5.2 历史抽屉（history-drawer）

- 顶部新增**视图切换**：「按时间」/「按批次」两个 tab 或分段控件（建议默认「按批次」，可切回「按时间」）。
- **按批次视图**：同 `batchId` 的 image 记录合并为一张**批次卡**：
  - 缩略图组：同批次图横向排列（最多 4 张，超出显示「+N」角标）；
  - 右上成功计数徽标（如 `4/4`，即 成功张数/总张数）；
  - 配方摘要行：prompt 摘要 + model / 比例；
  - 批次卡展开/悬浮时，单张缩略图仍可点选（查看大图）、拖入画布（复用 `application/history-image` 语义）、逐张复现。
- **按时间视图**：保持现有单图流水展示，行为不变（兼容旧习惯）。
- 无 `batchId` 的旧记录：在按批次视图下按单图卡回退展示，不丢失。

## 6. 非目标（明确不做）

1. **不改 jsonl 底层模型**：history.jsonl 保持单行 append-only，`batchId` 只是可选字段，读侧分组，不做行合并/重写。
2. **不做素材编辑/导出/上传**：R1 title/note 编辑、R6 CRUD/导出导入、R4 外部上传均不在本期 P0（R1/R4 仅列 P1 可选）。
3. **不碰锁定/去重逻辑**：hashRef 指纹主键、adopted/locked 三态语义、removeChildren 锁定保护全部保持现状，零改动。
4. **不做入口语境分离**（R5 历史不自动弹/资产全屏）、素材 kind 扩展（R9）、云同步（R10）。
5. **不做批次级「一键恢复会话」**（R7，仅列 P1，本期不交付）。
