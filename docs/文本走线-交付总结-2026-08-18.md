## 3. 关键实现

- **反推归位**：删 `runImageReverse` 与 image-gen 反推开关/UI；`runTextGen` 接收上游 data:image 图 → 描述文本写回文本节点自身；非 data:image 上游明确报错不静默丢图。
- **文本走线**：删旁路 `applyTextToDownstream`（三处联动统一「写 outputText + 标下游 stale」，下游 prompt 永不被覆盖）；`composeImagePrompt` 唯一 prompt 合成入口（上游文本按连线序拼接 + 自身 prompt 追加在后，trace 记录合成 prompt）。
- **生成回写（Q1）**：文生图/图生图 count=1 第 1 张统一写回自身顶掉（旧图入历史）；锁定保护沿用（锁定图不顶掉、改建产出节点）；count>1 第 2..N 张建产出节点；图生图不再清空源节点 imageUrl。
- **素材节点（Q3）**：同型 image-gen + `isAsset` 顶层标记；拖图空白→素材（整卡显图/角标「素材」/无指令面板/不可运行/可连线）；拖图到文本卡→自动建素材+连线；isAsset 16 项判分支全核对。
- **连线规则**：图片→文本（反推）、文本→图片（关键词）、图片→图片（参考）放行；文本→文本、任何→素材拒绝。
