## 四卷交付内容

### 4.1 图像编辑与画布生产力
- **蒙版局改**（B1）：`mask-editor.ts` 笔刷/橡皮/撤销重做/半透明蒙版；accepted 后只轮询原任务不重投；失败保留蒙版提示词；错误带 remoteTaskId
- **多角度**（B2）：`angle-editor.ts` 7 预设 + 自定义说明 +「不保证几何一致」提示；无图片参考能力模型不显示入口
- **@素材引用**（B3）：cmd-panel `@` 触发资源选择器 + 结构化 `mentions[]` 持久化 + 丢失标红阻止提交 + 同名按 id 绑定
- **.icbundle**（C）：`bundle_api.py` 导出项目/选中节点、SHA-256 去重、路径穿越校验、原子回滚、无 Key

### 4.2 视频与音频画布
- **视频闭环**（A）：startFrame/endFrame、submitting/accepted/processing 状态细分、每 Key 并发 1、close-guard 媒体任务检测、查看器加入资产/失效恢复
- **音频全链路**（B）：`audio_api.py` 三段协议 + adapter 表 + mutagen 元数据；`audio-gen` 节点；未配置音频模型时不出现可运行按钮（合规降级）；导入音频不 base64 进 .icproj
- **媒体资产/历史/关联**（C）：MediaAssetRecord 通用资产、资产抽屉媒体筛选、历史 video/audio tab、audio-ref 连线「音轨」标签、模型不支持音频时运行前明确提示

### 4.3 提示词资产项目与模型配置
- A 视觉提示词库 / B .icbackup 整包备份 / C 最近项目+主题：架构师审计确认已实现 + QA 复验通过
- **D 模型能力 schema**（新增）：ModelCapabilitySpec + 用户 schema 覆盖层 + custom-declarative 白名单防注入（拒绝 eval/headers/__proto__/api_key）+ capability_schemas.json 随备份

### 4.4 MONOFORM 导演台（独立子产品）
- `src/director/*` 27 个 TS 文件：D0 壳/工程文件（.icdirector v1 + 迁移）→ D1 场景视口（Three.js/GLB 导入/变换/吸附）→ D2 镜头参考图 → D3 光照人物（原创白模/IK）→ D4 时间轴导出（MP4 独立 Worker：OffscreenCanvas+MediaRecorder）→ D5 与主画布互通（director-bridge，trace 记录导演工程/相机/时间点）
- WebGL 不可用静态降级；启动：选中图片节点 → 操作条「导演台」按钮
