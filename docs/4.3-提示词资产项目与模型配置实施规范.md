# 4.3：提示词、资产、项目与模型配置实施规范

> 目标：补齐参考项目“桌面创作工作台”的内容管理能力，但保持 Infinite Canvas 的本地文件与 `.icproj` 体系。

## 1. 切片 A：视觉提示词库

### A1. 数据模型

现有收藏文本迁移到可扩展的本地 `prompt_library.json`：

```ts
interface PromptCard {
  id: string;
  title: string;
  prompt: string;
  summary?: string;
  categoryId?: string;
  tags: string[];
  coverPath?: string;      // 本地拷贝；不是外链
  favorite: boolean;
  createdAt: number;
  updatedAt: number;
  source: 'builtin' | 'user';
}
```

- 内置包可有分类、封面、标题、摘要，但必须由本项目重新创作；不可拷贝参考项目 12 条 prompt/封面。
- 用户可新增、编辑、删除自己的卡，替换封面，收藏、搜索、筛选、复制、插入当前节点。
- 内置卡删除语义为“隐藏/恢复默认”，不能污染安装包。

### A2. 交互与上下文

- 项目主页有“提示词灵感区”；画布左侧资源抽屉继续提供搜索和插入，不创建第三套数据源。
- 插入有三个明确动作：替换当前 prompt、追加当前 prompt、作为文本节点放入画布。
- 卡片封面图片进入项目资源目录或用户应用数据目录；不写入浏览器 localStorage。

**验收 A**：旧收藏不丢；无封面时有稳定占位；替换封面、关闭应用、重开仍存在；插入动作不自动运行模型。

## 2. 切片 B：资产导入导出与整包备份

### B1. 三种文件，不能混淆

| 文件 | 内容 | 用途 |
|---|---|---|
| `.icproj` | 单项目画布与轻量元数据 | 日常保存 |
| `.icbundle` | 单项目 + 实际媒体文件 | 项目迁移/分享（4.1） |
| `.icbackup` | 多项目、资产、提示词、工作流、设置的 ZIP | 个人备份/换电脑 |

### B2. `.icbackup` 规则

```text
manifest.json
projects/*.icproj
assets/<content-hash>.<ext>
prompt-library.json
workflows.json
settings.json（不含 API Key）
```

- 导出前估算大小、显示包含范围；大于阈值时让用户选择“仅元数据 / 含媒体”。
- 导入先解压到临时目录，校验 schema、hash、大小、路径穿越、MIME；完全成功后才原子写入。
- 冲突策略必须由用户选择：新增副本、按 ID 合并、跳过；默认新增副本。
- API Key 永远不在默认导出；恢复后提示重新配置渠道。

**验收 B**：备份到新目录恢复后，项目、资产、提示词、工作流完整；损坏 ZIP 不改写任何当前数据；包中无 Key。

## 3. 切片 C：项目主页与项目管理

### C1. 最近项目

在设置文件中维护最多 30 条：`path`、`name`、`lastOpenedAt`、可选封面缩略图路径。

- 项目主页显示新建、打开、最近项目、移除记录；移除记录绝不删除文件。
- 打开前检查路径存在；失效项目可清理记录或重新定位。
- 项目卡有重命名显示名、在文件夹中显示、复制路径；真实重命名文件需明确确认并处理同目录资源，首期可不做。

### C2. 主题

- 支持主题 token 系统而非复制参考项目色值：至少“当前暖白、当前深色”外加三套本项目原创主题。
- 每套主题定义画布、节点、连接、悬浮层、状态色 token；禁止散落 CSS 硬编码。
- 动态背景只用于项目主页，必须支持减少动态效果与低性能降级，不能影响画布帧率。

**验收 C**：切主题后所有面板可读；最近项目失效不阻塞新建；打开旧 `.icproj` 不自动套模板。

## 4. 切片 D：模型能力 schema 与配置编辑

### D1. 原则

现有多供应商/多 Key 机制保留。新增的是**声明式能力 schema**，不是在设置中执行任意 JavaScript。

```ts
interface ModelCapabilitySpec {
  modelId: string;
  kinds: Array<'chat' | 'drawing' | 'video' | 'audio'>;
  image?: { referenceImages?: number; maskEdit?: boolean; angle?: boolean; aspectRatios?: string[] };
  video?: { imageReference?: boolean; startEndFrame?: boolean; audioInput?: boolean; seconds?: number[] };
  audio?: { duration?: number[]; formats?: string[] };
  requestAdapter: 'openai-image' | 'gemini-native' | 'fluxport-video' | 'custom-declarative';
}
```

- 内置规则仍由后端维护；用户可添加/覆盖 schema，但校验字段、预览请求结构、回退与删除必须完整。
- `custom-declarative` 只能描述 URL path、字段映射、状态字段和结果字段白名单；禁止 `eval`、任意脚本、任意 Header 注入。
- 自定义 adapter 测试只能发送“测试连接/模型列表”请求，生成测试需用户单独确认费用。

### D2. 验收

- 一个自定义视频或音频模型可被安全配置并在对应节点中显示正确参数。
- schema 缺字段/校验失败时不可保存为可运行模型。
- 导出项目与备份不含 Key；schema 可随设置备份。
