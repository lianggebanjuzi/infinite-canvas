## 2. 产品目标

**一句话**：让「线」成为文本与图片之间唯一的数据通道——上传图=素材可反推、文本=关键词可生图、文本节点可编辑可顶掉、全程无旁路暗改。

**验收标准（可测量）**：

| # | 验收标准 |
|---|---|
| A1 反推走线闭环 | 上传/拖入绿植图 → 建素材节点 → 连到文本节点 → 文本节点输入命令「反推描述这张图」→ 运行 → 描述文本写入**文本节点自身**（outputText 可见、可点卡编辑）；画布上存在 素材→文本 连线；**不再产生游离的、不连线的反推文本节点** |
| A2 文本关键词生图 | 文本节点（反推结果或手写文案）→ 连到自建图片节点 → 自建图片节点自身 prompt 为空**也可运行** → 生成图写回自建节点自身（顶掉上一张）；该次生成的 trace 中 prompt 可见上游文本内容（线即真相可回溯） |
| A3 文本节点可编辑可顶掉 | 文本节点结果可直接点卡就地编辑；**编辑/重跑/历史回填后均不再覆盖下游图片节点 prompt（旁路消失）**，仅下游标 stale；重新运行顶掉旧 outputText（不累积），textHistory 保留可回填 |
| A4 上传图 = 素材 | 拖图/上传到画布空白 → 素材节点（整卡显示图、角标「素材」、无指令面板、无模型/发送控件、**不可运行**）；可连线作下游自建图片节点的参考图（图生图）与文本节点的反推源 |
| A5 回归 | 图片→图片 参考图语义不变（getReferenceImages 仍只取直接上游 imageUrl 一层）；脏标记全下游 BFS 不变；锁定保护不变（回写不顶掉锁定图，改走产出节点）；撤销/重做、历史、资产库不退化 |

**三个正交目标**：
1. **反推归位**：反推从「image-gen 上的隐藏开关 + 游离产出」改为「文本节点的显式输入（上游图走线）」，结果归位到文本节点自身。
2. **线即真相**：删除文本旁路暗改，文本→图片的关键词完全走线；线的方向 = 数据依赖方向。
3. **单卡迭代**：上传图=纯素材、自建图=可无限顶掉迭代，节点「产物型/操作型」的双重人格收敛为「数据 vs 生成」的明确区分。

## 3. 用户故事（园艺电商设计师视角）

1. As 园艺电商设计师，I want 把客户发来的花园实拍图拖进画布得到一张「素材卡」、拉一条线到文本卡输入「反推这张图的场景描述」，so that 我能把真实场景快速变成可复用的提示词文本，而不用在图片卡上找藏在模型 chip 里的反推开关。
2. As 园艺电商设计师，I want 把写好的主体文案卡连到花盆生图卡、再挂一张材质参考图素材卡，so that 文案作为关键词、素材作为参考图都显式走线，改文案后我只重跑生图卡就能得到新图，不用担心某处被「偷偷改掉」的提示词。
3. As 园艺电商设计师，I want 文本卡的反推结果直接点一下就能就地修改、再运行一次就顶掉旧描述，so that 我能在一张卡上反复打磨提示词，改完下游自动标黄提醒我重跑。
4. As 园艺电商设计师，I want 一张素材卡可以同时连给「反推文本卡」和「生图卡」当参考图，so that 同一张产品图既能被描述、又能当图生图底图，素材不重复上传、线看得清。

## 5. 交互变化描述（文字稿，非高保真）

### 5.1 图片 ↔ 文本 连线建立方式

- **方式 A（拖线直连）**：从图片节点（素材或自建）out 端口拖出 → 松手到文本节点任意位置 → 建立 图片→文本 连线（反推输入）。校验通过 toast「已创建连线」；文本节点及其下游标 stale。
- **方式 B（拖线 + 新建）**：从图片节点拖线到空白 → 新建节点菜单出现「文本」「图片生成」候选 → 选「文本」→ 建文本节点并自动连线（文本节点出现在松手处）。
- **方式 C（拖图直投，建议）**：把本地图片/历史图直接拖到文本节点卡片上 → 自动建素材节点并连线（素材→文本）。不再出现「文本节点不接收图片」。
- **仍拒绝的组合**：文本→文本 连线（返回「文本节点不能作为输入」或改为「暂不支持文本连文本」）；任何→素材节点 连线（素材是链首数据，不接收上游）。

### 5.2 反推触发

- 选中**文本节点**（已连图片上游）→ 指令面板输入命令（如「反推这个图片」「描述这张图」）→ 发送 → 文本模型看图 + 命令 → 结果写入文本节点自身 outputText（卡片文本区显示、可点卡编辑）；同一次运行顶掉上一版反推文本（textHistory 仍可回填）。
- **不再有** image-gen 上的「文本模型」反推开关：图片节点模型 chip 只有绘图模型，卡片上不再出现「反推」入口。
- 上游图须为内嵌 data:image（本地拖入天然满足）；旧项目 http 图反推仍不支持（明确报错，不静默丢图）。

### 5.3 文本如何成为关键词

- 文本节点 → 连到自建图片节点 → 该图片节点运行时，**最终 prompt = 上游文本（按连线顺序拼接）+ 自身 prompt（非空追加）**；自身 prompt 可空。
- 多个文本节点连同一图片节点：按连线建立顺序拼接（建议；最终见 Q2）。
- 文本结果被就地编辑 / 重新运行 / 历史回填后：**不再偷偷覆盖下游 prompt**；下游图片节点自动标 stale（黄），用户重跑图片节点即用新文本。
- 图片节点生成的 trace 记录最终合成 prompt，便于回溯「这张图用了哪些文本」。

### 5.4 文本节点编辑 / 顶掉表现

- 点击文本节点内容区 → 进入就地编辑（textarea）→ 失焦或 Enter 保存；Escape 取消。保存后 outputText 更新、下游标 stale、**不再改下游 prompt**。
- 重新运行文本节点：新结果**顶掉**旧 outputText（卡片不累积成多份）；textHistory 保留全部历史，可点击回填。
- 空态：无结果时显示占位文案（建议「点击输入文本；连接上游图片可反推」）。

### 5.5 上传图素材节点表现

- 拖图/上传到画布空白 → 生成「素材」节点：整卡显示该图（imageUrl=图本身）、角标「素材」、**无指令面板**（选中时不显示模型/比例/发送等生成控件）、**不可运行**。
- 素材节点可拖出连线：连到自建图片节点 = 参考图（图生图）；连到文本节点 = 反推源。
- 素材节点仍可双击查看大图、采纳/锁定、删除、拖动。
- 素材节点不进入「新建节点」菜单（只能拖图/上传/双击选图产生）。
