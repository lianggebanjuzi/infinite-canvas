# 无边框窗口与视觉精修实施指导

> 日期：2026-08-14
> 目标：消除"网页套系统壳"的廉价感，让 Infinite Canvas 达到主流精致桌面软件（自绘标题栏 + 内容融合）的观感。
> 范围：① 无边框窗口 + 自绘标题栏；② 画布点阵加深；③ 顶栏与窗口融合。**不含空态引导**（已明确不做）。

---

## 0. 病灶回顾（为什么现在看起来不精致）

| # | 病灶 | 根因 |
|---|------|------|
| 1 | 窗口顶部两条白横条叠在一起 | Windows 原生标题栏 + 应用内 44px 白顶栏并存 |
| 2 | 画布像一块空白板，没有工作区质感 | 点阵 `--canvas-dot: #EDEAE4` 对底色 `#FAF9F6` 对比度过低，约等于不可见 |
| 3 | 顶栏"薄"且与系统标题栏糊成一片 | 顶栏纯白底 + 13px 灰字，颜色与原生标题栏几乎一致 |

设计 Token（配色/圆角/阴影）本身没有问题，本轮不动 Token 体系，只改窗口壳、点阵、顶栏三处。

## 1. 无边框窗口 + 自绘标题栏

### 1.1 修改窗口创建参数（`main.py:305`）

```python
window = webview.create_window(
    title     = 'Infinite Canvas 1.0',
    url       = INDEX_HTML,
    js_api    = api,
    width     = 1400,
    height    = 900,
    resizable = True,
    min_size  = (800, 600),
    frameless = True,      # 新增：去掉 Windows 原生标题栏
    easy_drag = False      # 新增：必须关掉！默认拖动整个窗口，会和画布平移/框选冲突
)
```

> `easy_drag` 是 pywebview 的"按住任意位置拖窗口"模式，对本项目是灾难（拖画布 = 拖窗口），必须显式设为 `False`，拖拽改由 1.4 的顶栏专属逻辑接管。

### 1.2 API 层新增窗口控制方法（`main.py` 的 `InfiniteCanvasAPI` 类）

```python
def win_minimize(self):
    webview.windows[0].minimize()

def win_toggle_maximize(self):
    # pywebview 的 maximize()/restore() 是两个方法，用一个标志位切换
    win = webview.windows[0]
    if getattr(self, '_win_maximized', False):
        win.restore()
        self._win_maximized = False
    else:
        win.maximize()
        self._win_maximized = True

def win_close(self):
    webview.windows[0].destroy()

def begin_drag(self):
    # Windows 原生拖拽手感：把顶栏mousedown转成系统的"按住标题栏"消息
    # 附带获得：拖到屏幕边缘自动贴边/最大化（Aero Snap）免費可用
    import ctypes
    user32 = ctypes.windll.user32
    hwnd = getattr(self, '_hwnd', None)
    if not hwnd:
        hwnd = user32.FindWindowW(None, 'Infinite Canvas 1.0')  # 标题须与 create_window 完全一致
        self._hwnd = hwnd
    if hwnd:
        user32.ReleaseCapture()
        user32.SendMessageW(hwnd, 0x00A1, 2, 0)  # WM_NCLBUTTONDOWN + HTCAPTION
```

要点：
- `begin_drag` 必须在鼠标还按着的时候被调用才有效，所以前端要在 `mousedown` 事件里**同步触发**（见 1.4）。实测 WebView2 桥接延迟足够低，正常可用。
- `FindWindowW` 依赖窗口标题精确匹配，标题改了这里要同步改。
- 如果将来想要跨平台（macOS/Linux），`begin_drag` 内部要做平台分支；当前只考虑 Windows 可不管。


JS（放在 `src/v1/main.ts` 初始化段，或就近的 UI 模块）：

```typescript
// 窗口控制
document.getElementById('win-min')!.addEventListener('click', () => window.pywebview.api.win_minimize());
document.getElementById('win-max')!.addEventListener('click', () => window.pywebview.api.win_toggle_maximize());
document.getElementById('win-close')!.addEventListener('click', () => window.pywebview.api.win_close());

// 顶栏拖拽：只有点在"非交互区域"才触发拖窗口；双击顶栏 = 最大化/还原
const topbar = document.querySelector('.topbar')!;
topbar.addEventListener('mousedown', (e) => {
  const t = e.target as HTMLElement;
  if (t.closest('input, button')) return;          // 输入框/按钮上不抢事件
  if ((e as MouseEvent).button !== 0) return;      // 只响应左键
  window.pywebview.api.begin_drag();
});
topbar.addEventListener('dblclick', (e) => {
  const t = e.target as HTMLElement;
  if (t.closest('input, button')) return;
  window.pywebview.api.win_toggle_maximize();
});
```

> 类型说明：`window.pywebview` 的全局声明在 `src/types/globals.d.ts`，如果新方法报错找不到属性，在声明里补上 `win_minimize(): Promise<void>` 等四个签名。

### 1.5 Windows 11 圆角补偿（可选但建议）

无边框窗口在 Win11 上可能变成直角 + 丢阴影。用 DWM 接口（桌面窗口管理器，代码里叫 DWM）把圆角要回来，在 `main.py` 窗口创建后加：

```python
def _apply_rounded_corners():
    try:
        import ctypes
        hwnd = ctypes.windll.user32.FindWindowW(None, 'Infinite Canvas 1.0')
        if hwnd:
            pref = ctypes.c_int(2)  # DWMWCP_ROUND：强制圆角
            ctypes.windll.dwmapi.DwmSetWindowAttribute(hwnd, 33, ctypes.byref(pref), 4)  # 33 = DWMWA_WINDOW_CORNER_PREFERENCE
    except Exception:
        pass  # Win10 等不支持的环境静默跳过
```

在 `webview.start(...)` 之前调用一次即可（hwnd 此时可能尚未生成，若无效则改为在窗口 `shown` 事件里调用：`window.events.shown += lambda: _apply_rounded_corners()`）。

## 2. 画布点阵加深（`src/v1/styles/variables.css` + `app.css`）

现在：底色 `#FAF9F6`，点 `#EDEAE4`，1px / 28px —— 约等于看不见。

```css
/* variables.css */
:root { --canvas-dot: #E3DED5; }            /* 原 #EDEAE4，压深一档 */
```

## 3. 顶栏与窗口融合（`src/v1/styles/app.css`）

无边框之后，顶栏就是窗口的"脸"，要和画布同色系、与窗口融为一体：

```css
.topbar {
  background: var(--bg-app);            /* 原 var(--bg-panel) 纯白，换成画布同款米白 */
  border-bottom: 1px solid var(--border-soft);  /* 保留细分隔线，不变 */
  /* 其余不变 */
}
```

效果：顶栏和画布连成一整块暖米白，白色只留给真正需要"浮起来"的元素（底部胶囊条、指令面板、卡片），视觉层级自然就出来了——这正是参考软件"精致感"的来源：**背景统一、内容分层**，而不是到处白底。

## 4. 风险与回退

| 风险 | 说明与对策 |
|------|-----------|
| 边缘拖拽缩放可能失效 | 部分环境下无边框窗口失去原生缩放边。先实测；若失效，可接受（只留最大化/还原）或进阶处理 `WM_NCHITTEST` 消息自绘 8px 缩放热区（工作量大，不建议第一版做） |
| `begin_drag` 偶发不跟手 | WebView2 桥接是异步的，极端情况下消息到达时鼠标已松开。如遇此问题，退化为 JS 方案：`mousedown` 记起点，`mousemove` 里调 `window.move()`（需在 API 暴露），缺点是无 Aero Snap |
| Win10 无圆角 | 1.5 的调用已 try/except，Win10 上窗口为直角，属可接受差异 |
| 回退 | 删掉 `frameless/easy_drag` 两行 + 隐藏 `.topbar-right` 即恢复原状，改动全部可逆 |
