# Contributing

Thanks for your interest in Infinite Canvas.

## Development Setup

```bash
npm install
pip install -r requirements.txt
npm run build
python main.py
```

## Before Opening a Pull Request

- Run `npm run typecheck`.
- Run `npm run build`.
- Keep local configuration files out of commits.
- Avoid committing API keys, personal paths, generated archives, or build output.
- For UI changes, include a short description and screenshots when possible.

## Project Direction

The project focuses on local-first AI creative workflows, card-based composition, and maintainable desktop tooling. New features should fit the existing card, command, state, and provider patterns where possible.
