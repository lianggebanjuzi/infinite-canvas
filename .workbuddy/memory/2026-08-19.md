## Bug 修复：图片节点错误显示文本模型

- **问题**：图片节点（`image-gen`）的模型选择列表中出现了本不该存在的模型选项（例如来自名为 "文本" 的 key 下的 `gpt-image-2`）。
- **原因**：`src/v1/api.ts` 中的 `fetchImageModels` 函数在过滤 "text" 类型 key 时，只使用了 `keyName.includes('text')` 进行英文匹配。用户在配置中将某个 key 命名为中文 "文本"，导致过滤失效。
- **修复**：修改 `src/v1/api.ts`，在过滤条件中增加中文 "文本" 的匹配：`if (keyName.includes('text') || keyName.includes('文本')) return;`。

## Bug 修复：指令输入框下方显示"最终 prompt"预览

- **问题**：在图片节点选中后，指令输入框下方会显示一个"最终 prompt：xxx"的预览行，用户不需要此功能。
- **原因**：`src/v1/ui/cmd-panel.ts` 中的 `_renderPromptPreview` 函数会在 `image-gen` 节点选中时显示 `composeImagePrompt` 的完整结果。
- **修复**：修改 `_renderPromptPreview` 函数，使其直接隐藏 promptPreview 元素（`this.promptPreview.hidden = true;`），不再显示最终 prompt 预览。
