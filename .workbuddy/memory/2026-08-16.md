## 右键菜单失效大 Bug 修复（根因：撤销栈单例名撞 window.history）

- **根因**：vite `removeModuleAttribute` 插件使前端以经典脚本加载，bundle 顶层 `var history = new HistoryStack()` 落入 window 全局；`window.history` 是只读 accessor，sloppy 模式赋值静默失败 → `history` 仍是浏览器 History 对象 → 所有 `history.record()/undo()` 抛 TypeError 被静默错误处理吞掉 → 右键菜单删除/新建、Ctrl+Z/Y、Delete、run 引擎 suspend/resume、打开项目 clear() 全部静默失效（用户报"很多 bug"的根）。
- **修复**：单例 `history` → `flowHistory`（9 源文件 + 1 smoke）；main.ts 全局错误处理从完全静默改为 console.error 输出（不渲染 UI）。
- **根治**：`vite.config.ts` 加 `build.rollupOptions.output.format: 'iife'`，顶层变量封闭进 IIFE，彻底隔离 window 全局（防 history/name/status/top/location 同类再犯）。
